# Thème Dolibarr - Quarante Deux
Le thème Quarante Deux est une solution pour améliorer l'apparence et l'expérience utilisateur de Dolibarr. Grâce à son design élégant et ergonomique, il offre une navigation plus facile, une mise en page claire et une typographie améliorée pour une meilleure lisibilité.
## Fonctionnalités
- Un design élégant et moderne avec une typographie améliorée pour une expérience utilisateur agréable.
- Une ergonomie améliorée avec une navigation plus facile et une mise en page plus claire pour un gain de temps et une productivité accrue.
- Une compatibilité avec les modules Dolibarr standard pour une utilisation sans problème
- Des raccourcis ont été ajoutés, ils sont consultables via le raccourci "option/alt + H"

## Intégrations
Le Thème incorpore les modules `ScriptsInject` & `HideTopMenu`

### - Scripts Injects :
ScriptsInject est un module qui permet d'incorporer des scripts javascripts en haut ou en bas de page à votre Dolibarr

![interface_scriptsinject](../custom/themequarantedeux/img/doc/scriptsinject_1.png)

Les urls peuvent etre ajouter en cliquant sur le bouton + 

![interface_ajout_scriptsinject](../custom/themequarantedeux/img/doc/scriptsinject_2.png)

### - HideTopMenu :
Le module HideTopMenu permet de cacher les menus du haut de Dolibarr selon une configuration.

Le module n'ajoute aucun menu et est très simple d'utilisation.

#### - Fonctionnement
il suffit de se rendre dans la configuration du module.

Ici, tous les menus pouvant être caché sont listés.

![Liste des menus pouvant être caché](../custom/themequarantedeux/img/doc/hidetopmenu_1.png)

Pour cacher un menu, il suffira de cliquer sur le bouton modifier, de le selectionner et d'enregistrer la configuration.

![Liste des menus pouvant être caché en mode édition](../custom/themequarantedeux/img/doc/hidetopmenu_2.png)

Le menu sera alors caché.
